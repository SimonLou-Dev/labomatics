🔤 Typographie

Trois familles de polices pour une hiérarchie claire et lisibilité optimale.

Display / Logo
Montserrat Bold 700

Utilisée pour les titres, logos, branding. Audacieux et mémorable.

Corps de Texte
Inter Regular 400 — Corps large
Inter Regular 400 — Corps régulier, pour articles et documentation
Inter Regular 400 — Corps petit, pour labels et captions

Hauteur de ligne: 1.6 pour lisibilité optimale. Largeur max: 65 caractères.

Code / Terminal
JetBrains Mono Regular 400
JetBrains Mono Bold 600

Pour blocs de code, examples CLI, snippets techniques.

Fallback Fonts

font-family: 'Montserrat', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif; font-family: 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Helvetica Neue', Arial, sans-serif; font-family: 'JetBrains Mono', 'Courier New', monospace;

🌙 Mode Sombre

Couleurs en mode sombre

Orange Primaire: #FF8C00 (au lieu de #FF6B00) pour meilleur contraste

Texte: #F8F4EB sur arrière-plans sombres

Arrière-plans: #2A2A2A (pas du noir pur pour réduire la fatigue oculaire)

Rouille: #B8561F reste stable dans les deux modes

Compatibilité CSS Variables

:root { --color-primary: #FF6B00; --color-primary-dark: #FF8C00; --color-bg-primary: #FFFFFF; } @media (prefers-color-scheme: dark) { :root { --color-primary: #FF8C00; --color-bg-primary: #1F1F1F; } }

✨ Directives

Contraste et Accessibilité

Ratio de contraste minimum 4.5:1 pour texte sur tous les arrière-plans. Orange #FF6B00 sur crème #F8F4EB = 7.2:1 ✅

Logo Spacing

Minimum 20px de padding sur tous les côtés du logo. Ne pas rogner, modifier les proportions, pivoter, incliner ou distordre.

Dimensions Minimales

  • Logo Principal: 100px de largeur
  • Icône: 32px minimum
  • Web: Redimensionner avec SVG (pas de rastérisation)

Responsive

Mobile

Desktop

Utiliser flexbox/grid avec gap pour spacing cohérent sur tous les breakpoints.
