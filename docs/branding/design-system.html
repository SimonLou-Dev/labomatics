🔤 Mode Dyslexie-Friendly

Mode optionnel pour les utilisateurs dyslexiques. Activable via un bouton dans l'interface.

Adjustements Appliqués

  • Letter-spacing: +0.05em (écarter les lettres)
  • Line-height: 1.8 (au lieu de 1.6) — plus d'espace entre lignes
  • Word-spacing: +0.1em — séparation des mots
  • Font-size: +2% globalement
  • Text-align: Toujours à gauche (jamais justified)
